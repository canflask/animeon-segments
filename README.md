# AnimeOn Community Skip

Общественная GitHub-база таймкодов для автоматического пропуска опенингов и эндингов в AnimeOn Toolbox.

Система похожа на SponsorBlock по идее:

- зритель отмечает начало и конец фрагмента;
- расширение подписывает предложение публичным ником AnimeOn;
- опенинг и эндинг отправляются одной заявкой и одним JSON-блоком;
- после однократного подключения GitHub App расширение создаёт Issue напрямую, без отдельного сервера;
- владелец ставит метку approved, после чего GitHub Action автоматически обновляет main;
- пользователи получают обновлённую базу автоматически;
- база кэшируется на 6 часов и продолжает работать при временной недоступности GitHub.

Никакой JavaScript с GitHub не исполняется. Скрипт загружает только JSON, проверяет поля и использует только категории opening и ending.

Автор Community Skip и GitHub-интеграции: canflask.

## Формат записи

~~~json
{
  "id": "d632b8ba-d8e2-42d4-a8ce-5721b3872d24",
  "animeId": 12345,
  "animeSlug": "nazvanie-anime-12345",
  "episode": 1,
  "translation": "*",
  "category": "opening",
  "segment": [74.2, 163.85],
  "submittedBy": "canflask",
  "status": "approved"
}
~~~

Этот пример показан только в документации и не включён в активную базу.

## Что означают поля

| Поле | Значение |
| --- | --- |
| id | Уникальный ID, его создаёт скрипт |
| animeId | Число в конце адреса страницы AnimeOn |
| animeSlug | Последняя часть адреса страницы |
| episode | Номер серии |
| translation | Звёздочка для всех озвучек или точное название |
| category | opening или ending |
| segment | Начало и конец в секундах |
| submittedBy | Публичный ник автора на AnimeOn без @ |
| status | В опубликованной базе только approved |

## Проверка

Локально:

~~~text
npm run validate
~~~

На GitHub эта же проверка запускается автоматически для каждого изменения.

Инструкция по первой публикации находится в файле GITHUB_SETUP_RU.md.
