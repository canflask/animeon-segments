# Как добавить таймкод

## Самый простой способ

1. Откройте серию на AnimeOn во встроенном плеере.
2. В AnimeOn Toolbox откройте вкладку «Пропуск».
3. На начале опенинга или эндинга нажмите «Начало OP» или «Начало ED».
4. На конце фрагмента нажмите соответствующую кнопку «Конец».
5. Нажмите «Отправить через GitHub».
6. Проверьте готовое описание и создайте Issue.

## Как принять предложение в базу

1. Проверьте таймкод на той же серии.
2. Скопируйте JSON-объект из Issue.
3. Добавьте его внутрь массива segments в data/segments.json.
4. Убедитесь, что status равен approved.
5. Обновите updatedAt.
6. Создайте Pull Request или сохраните изменение прямо в main.
7. Дождитесь зелёной проверки Validate segments.

Ветка main считается опубликованной и проверенной базой. Клиент игнорирует записи с другим статусом и записи с ошибками.

## Правила

- Время указывается в секундах и может содержать сотые доли.
- Конец должен быть строго позже начала.
- Для одной серии, озвучки и категории хранится одна метка.
- Используйте translation: "*", если длительность совпадает во всех озвучках.
- Если озвучка имеет другое начало видео, укажите её видимое название из плеера.
- Не добавляйте рекламу: категории базы — только opening и ending.
