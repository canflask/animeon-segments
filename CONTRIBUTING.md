# Как добавить таймкод

## Самый простой способ

1. Откройте серию на AnimeOn во встроенном плеере.
2. В AnimeOn Toolbox откройте вкладку «Пропуск».
3. Заполните начало и конец OP, затем переключитесь на ED и заполните его границы.
4. При необходимости уточните выбранную границу кнопками ±0,1/±1 секунду.
5. Проверьте оба диапазона и нажмите «Отправить OP + ED».
6. Расширение создаст одну заявку с единым JSON-блоком; при сбое она целиком останется в локальной очереди.

## Как принять предложение в базу

1. Проверьте таймкод на той же серии.
2. Поставьте Issue метку approved.
3. Workflow «Принятие таймкода» прочитает JSON, проверит поля, добавит или обновит запись, изменит updatedAt и закроет Issue.
4. Убедитесь, что оба workflow завершились зелёным статусом.

Метка approved доступна только владельцу и участникам репозитория с правом управления Issue, поэтому обычный пользователь не может принять собственное предложение.

Ветка main считается опубликованной и проверенной базой. Клиент игнорирует записи с другим статусом и записи с ошибками.

## Правила

- Время указывается в секундах и может содержать сотые доли.
- Конец должен быть строго позже начала.
- Для одной серии, озвучки и категории хранится одна метка.
- Используйте translation: "*", если длительность совпадает во всех озвучках.
- Если озвучка имеет другое начало видео, укажите её видимое название из плеера.
- Не добавляйте рекламу: категории базы — только opening и ending.
